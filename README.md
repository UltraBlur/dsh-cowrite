# dsh-cowrite — 共写文档

DeepSeek Harness 插件：在**右侧栏**新增一个可编辑的 Markdown「共写」标签页，用来和助手共同编辑同一份文档。

## 用法

1. 打开任意会话，右侧栏点 **+**（新建标签页），在引导卡片里选 **共写文档**；
   或按 `Cmd/Ctrl+Shift+M` 直接打开。
2. 顶部下拉框选择工作区里的 `.md` / `.markdown` / `.mdx` / `.txt` 文件。
3. 工具栏中间切换视图：**排版**（默认，逐块就地编辑，类 Typora hybrid 模式）/
   **预览**（只读排版稿）/ **源码**（纯文本）。
4. 工具栏右侧是字号缩放：`−` / `百分比` / `+`，也可用 `Cmd/Ctrl+=`、`Cmd/Ctrl+-`、`Cmd/Ctrl+0`。
   缩放作用于整个文档（标题、代码、表格随正文一起放大），会记住上次选择。
5. 源码视图里直接输入：停止输入约 0.7 秒后自动写回磁盘；`Cmd/Ctrl+S` 立即保存。
6. 助手（或任何别的工具）改动了同一个文件时：
   - 这里没有未保存改动 → 自动载入磁盘最新内容；
   - 这里有未保存改动 → 顶部出现冲突提示，可选「载入磁盘版本」或「覆盖为我的版本」。

## 排版（hybrid）视图怎么用

- 打开文件时整篇按排版渲染；**点任意一段**即在该处展开源码编辑框，光标落在你点的字符上。
- `Enter`：普通段落处**断开成两个块**；列表/引用里**延续标记**（`- `、`2. `、`> `）；
  在空列表项上按 `Enter` 会**跳出列表**。
- `Backspace` 在块首：**并入上一块**。
- `↑` / `↓` 在块的首行/末行：跳到上一块/下一块。
- `Esc`：收起编辑框，回到纯排版。
- 编辑框里看到的是**该块的原始 Markdown**（标题带 `#`、列表带 `-`），和 Typora 一致；
  移开光标后立即按新语法重新排版。
- **表格**：点任意单元格 → 光标直接落在该单元格的文字里（不是表格末尾）；
  编辑框里用 `Tab` 在单元格之间依次移动、到末尾回到第一格；
  编辑表格时会出现 `+ 行 / ↑+ / + 列 / ←+ / − 行 / − 列` 与 `⇤ / ⇔ / ⇥`（本列左/中/右对齐）工具条，作用在光标所在行列。
  改对齐**只重写分隔行那一格的冒号**，破折号长度和原有空白都保留，列宽不会跳。
- **格式化快捷键**：`Cmd/Ctrl+B` 粗体、`Cmd/Ctrl+I` 斜体、`Cmd/Ctrl+E` 行内代码；
  有选中就包裹选中文字，没有选中就插入一对空标记并把光标放中间。源码视图同样有效。

## 排版取值来源

标题阶梯（2.25 / 1.75 / 1.5 / 1.25 / 1 / 1em）、正文 1.6 行高、`0.8em 0` 块间距、
引用 4px 竖条 + 15px 内距、单元格 `6px 13px` 与 32px 最小宽、代码 0.9em、
勾选框绝对定位到 `-1.3em`、搜索命中纯黄底黑字、大纲每级 1em 缩进、
焦点模式改用**变灰（#C8C8C8）而非整体透明**、打字机模式按
`(视口高 − 行高) / 2` 加内边距——这些数值是从 Typora 1.14.10 的
`style/base.css` 与 `style/themes/github.css` 里读出来的，逐条写进了
本插件的 CSS，并有 `typography.test.mjs` 的 28 条断言钉住。

## 大纲 / 查找 / 焦点模式

工具栏右侧三个按钮（也可以只用键盘）：

| 控件 | 快捷键 | 作用 |
| --- | --- | --- |
| `▤` 大纲 | — | 按层级树状列出标题，带 `▸/▾` 折叠开关，点条目滚到对应位置 |
| `⌕` 查找 | `Cmd/Ctrl+F` | 高亮全部匹配并显示 `当前/总数`；`Cmd/Ctrl+G` 下一个、`Cmd/Ctrl+Shift+G` 上一个、`Enter`/`Shift+Enter` 同效、`Esc` 关闭 |
| `◎` 焦点模式 | — | 只保留正在编辑的那一段清晰，其余文字变灰、图片降到 0.3 透明（悬停恢复），会记住开关 |

| `¶` 首行缩进 | — | 顶层段落首行缩进 2 字（列表内与行内重置，独占图片反向拉回 -2em），会记住开关 |

## 公式

行内 `$...$`、独占一行 `$$...$$`（块级居中）。渲染的是自研 TeX 子集，不是 MathJax：

- 多行环境：`matrix` / `pmatrix` / `bmatrix` / `Bmatrix` / `vmatrix` / `Vmatrix` / `aligned` / `align` / `gathered` / `cases` / `array`（`&` 分格、`\\` 换行）
- 定界与堆叠：`\left( \right)`、`\big \Big \bigg \Bigg`（含 `l/r/m` 变体）按级放大、
  `\binom` / `\dbinom` / `\tbinom`（**无分数线**，与参考的 Genfrac 厚度 0 一致）、
  `\genfrac{左}{右}{厚度}{样式}{分子}{分母}`、`\substack{a\\b}`、
  `\overset` / `\underset` / `\overunderset` / `\stackrel`、`\overbrace` / `\underbrace`、
  `\mathclap` / `\mathllap` / `\mathrlap` 零宽叠放
- 字体：`\mathbb \mathcal \mathscr \mathfrak`（映射到 Unicode 数学字母，含 `C/H/N/P/Q/R/Z` 这类 Letterlike 例外）、
  `\mathbf \boldsymbol \mathit \mathrm \mathsf \mathtt`、
  `\text` 系 `\textbf \textit \textrm \textsf \texttt \textnormal`
- 化学式：`\ce{H2O}`、`\ce{SO4^2-}`、`\ce{2H2 + O2 -> 2H2O}`（元素下标、电荷上标、`->` `-->` `<=>` 箭头、`*` 作 `·`）；
  这是 mhchem 的最小可用子集，不含同位素、晶体水合物、复杂反应条件
- 编号：`\tag{2.1}` 在显示公式右侧排 `(2.1)`，`\notag` / `\nonumber` 可抑制；行内公式不编号，
  也不会自动编号（与 MathJax 默认 `tags: none` 一致）
- 配色：`\textcolor{red}{x}`、`\color{blue}`（其后同组整体着色）、`\colorbox{yellow}{x}`、
  `\fcolorbox{red}{yellow}{x}`、`\definecolor{name}{rgb}{10,20,30}`；颜色只认十六进制、CSS 颜色名与 `rgb()`/`rgba()`，
  `url(...)`、`javascript:` 之类一律拒绝
- 框与间距：`\boxed \fbox`、`\sqrt[3]{}` 带根指数、`\pmod`、`\hspace{2em}` / `\kern` / `\quad`、
  `\iff \implies \lnot \dots \vdots \ddots` 等关系符
- 修饰：`\hat \bar \vec \tilde \dot \ddot \check \acute \grave`、`\overline \underline`、`\cancel \sout`、`\phantom`
- 间距：`\,` `\;` `\:` `\!` `\quad` `\qquad`
- 希腊字母与常用符号：`\alpha \Delta \lambda \times \pm \le \ge \approx \infty \partial \sum \int \to` 等约 70 个
- 上下标 `^` `_`、分式 `\frac{}{}`、根号 `\sqrt{}`、正体 `\text{}` `\mathrm{}`、粗体 `\mathbf{}`
- 不认识的命令**不会消失**，会按正体命令名显示，便于发现拼错

宏清单是照 `lib/MathJax4/tex-svg-full.js` 里 302 个命令键挑的可实现子集。
做不到的：自动连续编号与交叉引用（只能手写 `\tag`）、`\require` 扩展包、真正的数学字体度量、mhchem 的完整语法
（用的是系统衬线体 + CSS 排版，分式、根号、矩阵靠边框与表格画）。

## front matter / 提示块 / 脚注

- 文件首行的 `---` 围起来的块按 **front matter** 渲染（等宽、变淡、可横滚），不再被当成两条分隔线
- 引用块首行写 `> [!NOTE]`（也支持 `TIP` / `IMPORTANT` / `WARNING` / `CAUTION`）→ GitHub 风格提示块，
  竖条与标签颜色取自 base.css 的 `.md-alert-*`（#0969da / #1f883d / #8250df / #9a6700 / #cf222e）
- `[^id]` 渲染成灰底上标 chip，`[^id]: 内容` 渲染成带锚点的脚注条目，条目末尾有 `↩` 反向链接回到引用处；
  同一个脚注被多次引用时，引用锚点自动加 `-1`、`-2` 后缀以免撞号

## 自动配对

输入 `(` `[` `{` `"` `'` `` ` `` `*` `_` `~` `$` 会自动补上闭合符并把光标放中间；
有选中内容则包裹选中；遇到已存在的闭合符**直接跳过**而不是重复插入。
`*` `_` `~` `$` 在单词中间不配对（保证 `snake_case` 不乱），`"` `'` 紧跟在字母后也不配对。

## 列表符号保真

`-` `*` `+` 三种无序符号原样保留（渲染成 `data-mark` 并由 CSS 绘制），不会被统一成一种。

## [TOC] 目录

单独一行 `[TOC]` 渲染成目录块：按层级缩进列出全文标题，点一条跳到对应位置；没有标题时显示「（暂无标题）」。

## 行内 kbd

`<kbd>Ctrl</kbd>` 渲染成键帽样式（灰底描边、等宽）。

## 标题锚点与内部链接

标题渲染时带 `id="dcw-h-<slug>"`（GitHub 风格 slug，重名依次 `-1`、`-2`）。
文中的 `[文字](#标题)` 会在窗格内滚动到目标标题；解析不到目标的 `#xxx` 仍按普通链接处理。

## 导出与打印

工具栏 `⤓` 把当前文档导出成**独立 HTML 文件**（内嵌本插件样式、`<title>` 取文件名、正文进 `#write`）。
直接打印（⌘P）走同一套 `@media print` 规则：隐藏工具栏/页脚/大纲/表格工具条、去掉限宽与内滚动、
标题与表格行/图/代码块/公式/图表 `page-break-inside: avoid`、标题避免尾随断页、
焦点模式变灰的段落打印成全黑，页边距 `18mm 16mm`。

## 正文行宽

文档区限宽 860px 居中、左右 30px 内边距、底部 100px——侧栏拉宽后不会出现一行几十字的长句。

## 代码块

围栏会带上语言属性；能识别的语言做**词法着色**（含多行构造：Python/Elixir 三引号、Shell/Ruby/PHP heredoc、
Rust/Swift/Julia 嵌套块注释、JS/TS 模板字符串里的 `${…}` 嵌套；以及 JS/TS 正则字面量 `/…/gi`（按前一记号区分除法）、
Ruby `%w[]` `%i{}` `%q()`、Perl `q//` `qw{}` `m//` `s///g` `tr///`、C/C++ 原始字符串 `R"(…)"`；开行号时整块先分词再按行切，不会把多行字符串切碎）（关键字/字符串/注释/数字，映射表含 js/ts/py/r/matlab/c/sh/sql/json/yaml/html/css/latex 及 `python`、`c++`、`bash` 等常见别名），
另有一条 `⌗` 开关给代码块加行号，块右上角有 `⧉` 复制按钮，点语言标签可就地改语言。

## 光标吸附与缩进

- 点击落在 `**粗**`、`` `码` ``、`[文](链)` 这类标记运行时，光标会**吸附到该内联节点的外侧**，
  而不是停在 `**` 中间（对应参考实现的 `md-expand`：节点露源码、光标推到外侧边界）
- 表格以外的行首 `Tab` 缩进两格、`Shift-Tab` 退两格
` ```math ` / ` ```latex ` 围栏按块级公式渲染，不当作代码。

## 计数与统计

页脚计数可点，按 词 → 字 → 行 → 分钟 循环，选择会记住。词数算法照参考实现：
CJK 每字计 1、其余按空白与标点分词、`don't` 这类缩写算一个词、纯标点不计数；
分钟按参考默认的 382 字/分钟折算，0 词显示「≤ 1 分钟」。

## 行内 HTML 与 HTML 块

白名单内的行内标签（`sup` `sub` `mark` `u` `s` `del` `ins` `small` `span` `abbr` `q`
`samp` `var` `code` `b` `i` `em` `strong` `br` `wbr` `time` `kbd` `a`…）解析成真元素，只透传
`class`/`title`/`href`，**不走 innerHTML**；白名单外的标签保持原样文本。
整块的 HTML（行首为标签）按块渲染，渲染前剥掉 `<script>` 与 `on*=` 内联事件。

图片可带尺寸：`![](a.png){width=300 height=200}`，尺寸属性组本身不显示。

## 图表（mermaid 子集）

` ```mermaid ` / ` ```flow ` 围栏按图渲染（自研 SVG，不引第三方库）：支持流程图
（`graph TD/LR`、`[]` `()` `{}` `(())` 形状、`-->` `-.->` `==>` 连线、`|标签|`、`%%` 注释、
`subgraph 名称[标题] … end` 子图（成员在同层聚拢，外面画虚线分组框并标注标题）、
`classDef 名 fill:#f96` + `class A,B 名` 节点样式（颜色走白名单））、
时序图（`participant`、`->>`/`-->>` 消息）与饼图（`"标签" : 值`，按比例着色并标百分比）。
布局按入度分层、同层按邻居重心做三轮扫描排序以压边交叉，短行居中对齐；连线是**正交肘形折线**
（TD 先竖后横、LR 先横后竖，正对时退化成一条直线），环也能摆下。无法解析的图（`classDiagram` 等）**退回代码块**而不是空白。

配色照 `mermaid.min.js` 的 default 主题：节点填充 `#ECECFF`、参与者 `#FFFFDE`、描边 `#9370DB`，
连线走 `currentColor`（因此跟随应用明暗主题）；`mermaid.css` 里 `--mermaid-flowchart-curve: linear`
对应直线走线、`--mermaid-sequence-numbers: off` 对应不编号；生命线用 zenuml CSS 的 `1px 5px` 虚线节奏。
时序图区分同步（实线箭头）与异步（虚线）、`-x` 失败（无箭头）。

## 粘贴富文本

从网页或 Word 复制一段内容粘贴时，会优先读剪贴板的 `text/html` 并转成 Markdown：
标题、粗斜体、`~~删除~~`、行内代码、链接、图片、有序/无序（含嵌套）列表、引用、代码块、分隔线、管道表格，
常见 HTML 实体一并解码；`<script>`/`<style>` 与未知标签被丢弃（只留文字）。
若转换结果与纯文本一致（没有结构），则交还给浏览器默认粘贴。

## 粘贴与拖入图片

在编辑框里粘贴截图或拖入图片文件，会自动写到**文档同目录的 `assets/`**（`image-YYYYMMDD-HHMMSS-xxxx.png`），
并在光标处插入 `![](assets/…)`。字节走 `POST /api/dsh-cowrite/upload`（JSON + base64），
同样受工作区根目录约束：非图片、越界路径、空数据都会被拒。

## 图片

`![](相对路径.png)` 会被改写为宿主的鉴权二进制路由 `/api/dsh-cowrite/raw`，
路径相对**当前文档所在目录**解析；只允许工作区内的图片（`png/jpg/jpeg/gif/webp/avif/bmp/svg`），
越界、非图片、超大文件都会被拒。

路径规则按参考实现（`getRealSrc`）对齐：`#片段` 单独保留、`\` 当分隔符、
`//host/x` 补 `http:`、`data:` 直传、`file://` 落在工作区内则转成相对路径（区外原样保留）。

## Markdown 支持范围

自研解析器（未引入任何第三方 markdown 库），覆盖：ATX 与 setext 标题、
段落与软换行、引用、有序 / 无序 / 任务列表（含视觉缩进）、管道表格（含对齐）、
围栏代码块（带语言标签）、分隔线、以及行内 `**粗体**`、`*斜体*`、`~~删除~~`、
`` `代码` ``、`$公式$`（占位渲染）、链接、图片、自动链接与反斜杠转义。
链接只允许 `http/https/mailto` 与相对路径，`javascript:` 之类一律不渲染为链接。

## 行为约定

- 保存是**比较-交换**：提交时带上本端最后看到的 `mtimeMs`，若磁盘已被改动则拒绝写入并返回磁盘内容，不会静默覆盖助手的修改。
- 写入先落临时文件再 `rename`，避免半截文件。
- 文件监听靠轮询 `stat`（前台约 1.1 秒、后台约 4 秒），只读一个 `stat`，不读全文。
- 所有路径都由主机侧解析并限制在工作区内（会话工作目录、默认目录或已注册工作区），越界路径直接拒绝。

## 安装与分发

**从 tarball 安装（不需要 npm 账号）**：

```sh
npm pack                                  # 在插件目录生成 *.tgz
```

然后在 DSH 里用 `plugin_manager` 的 `install_bundle` 指向这个 tgz 的绝对路径即可；
或把 tgz 发给别人，对方同样一步装上。已构建好的包在 `dist/`。

**从 npm 安装**（需先发布，见下）：`install_bundle` 指向包名。

**发布到 npm 需要**：注册账号 → `npm login` → 把 `package.json` 的 `name` 改成
`@<你的 npm 用户名>/dsh-cowrite`（scoped 包要 `--access public`）→ **同步改 `cordis.patch.yml`
里 loader 行的 `name`**，两者必须逐字一致 → 重新 `npm pack` 并把 tgz 装一遍验证 → `npm publish --access public`。

**当前仓库不是 git 仓库**：发布前建议 `git init`、提交、打 tag，npm 页面的 `repository` 字段才有意义。

`tests/` 里是 27 组离线测试（742 条断言），不需要浏览器：

```bash
cd tests && for f in *.test.mjs; do node "$f" | tail -1; done
```

`langdata.test.mjs` 校验关键字表：抽取到的语言有数据、C-like 继承链完整、别名映射正确、无表的语言回落到语法族。
`host.test.mjs` 只用假的 `webServer` 打桩，不起端口；`realdoc.test.mjs` 会经线上路由读工作区里最新的开题稿，
需要 DSH 正在运行；未设置 `COWRITE_TEST_ROOT` 时该组自动跳过（`SKIP`），端口自动取 `DSH_WEB_URL`。
`tests/manual/` 里是逐轮开发用的一次性探针，不属于自动回归。`harness.mjs` 是个迷你 React（真 state/effect），`live`/`panels`/`table` 等交互测试靠它驱动。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | 主机半：在 Web 载体上注册 `POST /api/dsh-cowrite`，负责列出 / 读取 / stat / 写入工作区文件 |
| `client.js` | 浏览器半：注册右侧栏标签页类型、编辑面板、快捷键与文案 |
| `cordis.patch.yml` | bundle 补丁，插入一行 loader 条目 |
| `locale/*.json` | 插件列表里显示的名称与描述 |
| `tests/` | 27 组离线测试（742 条断言）与迷你 React 测试台 |
| `ROADMAP.md` | 与 Typora 的差距清单（逐轮打勾） |
| `SUMMARY.md` | 交付说明：能力清单、验证方式、已知边界 |

## 局限

- 单文件编辑，没有差分视图 / 撤销栈（撤销用浏览器的输入撤销）。
- 冲突判断基于 `mtimeMs`，同一毫秒内的两次写入无法分辨；没有 CRDT 级别的并发合并。
- 代码块不做语法高亮（等宽 + 语言标签）。
- 任务列表的勾选框可以点，但它改的是文件内容（没有撤销栈，勾错了要自己改回来）。
- 公式只覆盖上述子集；数学排版靠 CSS，复杂公式（矩阵、多行对齐）会退化成一行。
- 自动配对不处理中文输入法一次上屏多个字符的情况（IME 提交走 `onChange`，不经过按键配对）。
- HTML 块的净化只有「剥 script + 剥 on* 属性」两条，`:style` 属性透传；行内 HTML 用白名单构造元素所以更严。
- 计数用参考的算法，但它在 `\uABFF` 之后不再逐字计数，所以谚文按词计。
- 导出只有 HTML 一种格式（无 PDF/Word），PDF 需要打印为 PDF 由浏览器完成；导出不含远程字体。
- 源码里没有提取到 zenuml 的布局模型（它用 HTML/CSS 而非 SVG），所以只借用了它的生命线节奏与配色变量。
- 图表是自己写的子集渲染，不是 mermaid 本体：子图只画分组框（不做独立分层），没有样式类与主题变量覆盖；正交走线是固定中分点肘形、
  交叉消除只做三轮重心扫描（mermaid 用 dagre/elk 做完整分层布局）；
  节点位置只按入度分层排，规模大时会挤。
- 「光标吸附」是 `md-expand` 的近似：参考实现是让节点就地露出一小段源码再把你推出去，我这边整块本来就是源码，
  只保留了「把光标推到标记外侧」这一半，没有节点级的局部渲染。
- 词法着色按**语法族**（`//`、`#`、`%`、`--`、`;`、标记、CSS、JSON）覆盖约 130 个语言名，取自参考实现自带的
  CodeMirror mode 表；**关键字表是脚本从 `mode.min.js` 里抽出来的**（21 个 mode 自带数据 + 共享的 C-like 定义），
  覆盖 36 个语言，脚本抽取不足的（python/r/sh/sql/perl）补手写表，两者取并集。
- 词法着色仍是轻量状态机（不是逐语言的完整 mode 状态机）：正则只在明确的表达式位置识别（`if (x) /re/` 这类
  语句位置不认）；heredoc 只认 `<<WORD` / `<<'WORD'` 形态；Perl/Ruby 的引号算子只认常见分隔符（模板字符串嵌套、正则字面量等边缘情况会走样）；未识别的语言按纯文本渲染。
- 代码块行号是 CSS 计数器，复制到的仍是纯代码（不含行号）。
- 查找高亮的匹配段不参与"点击定位光标"（点击该段时光标落在段尾）。
